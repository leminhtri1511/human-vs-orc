# ⚔️ Human vs Orc

**Human vs Orc** is a 2D mobile Real-Time Strategy (RTS) game developed with **Unity 6** and **C#**.

The project focuses on building a complete RTS gameplay architecture from the ground up, including unit control, resource gathering, building construction, combat, pathfinding, enemy AI, and other core strategy-game systems.

> 🎮 This project is developed as a learning project based on a Mobile RTS development course, with additional improvements and architectural changes made during development.

---

## 🎯 About the Game

In **Human vs Orc**, players control human units, gather resources, construct buildings, train an army, and defend against waves of Orc enemies.

The core gameplay revolves around:

* Managing units
* Gathering resources
* Building and upgrading structures
* Training combat units
* Defending against enemy waves
* Strategically controlling units during combat

The goal of the project is not only to create a playable RTS game but also to explore scalable and maintainable game architecture in Unity.

## 🚀 Getting Started

### Requirements

Recommended environment:

```text
Unity 6
JetBrains Rider / Visual Studio
Git
```

Older Unity versions may also work depending on package compatibility.

---

### Clone Repository

```bash
git clone https://github.com/leminhtri1511/human-vs-orc.git
```

Then navigate to the project:

```bash
cd human-vs-orc
```

---

### Open with Unity

1. Open **Unity Hub**
2. Select **Add Project**
3. Select the cloned `human-vs-orc` folder
4. Open the project using the appropriate Unity version
5. Wait for Unity to import all assets and packages
6. Open the main game scene
7. Press **Play**

---

## 🎮 Gameplay Loop

The basic gameplay loop is:

```text
Gather Resources
       ↓
Construct Buildings
       ↓
Train Units
       ↓
Build an Army
       ↓
Defend Against Orcs
       ↓
Expand & Survive
```

The player must balance the economy and military strength while responding to increasingly dangerous Orc attacks.
